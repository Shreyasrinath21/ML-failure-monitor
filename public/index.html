REST API reference

JSON endpoints served on the same host as this dashboard.

GET/api/healthService readiness and model version
GET/api/metricsKPIs, alerts, recent prediction history, PSI drift
POST/api/predictScore a telemetry payload and store the prediction
POST/api/agent/triageRun the local evidence-gathering incident agent
POST/api/batch/scoreScore a CSV batch and preserve job results
POST/api/feedbackRecord observed outcome: {"id":"...","failure":true}
POST/api/simulate?count=120Generate shifted telemetry to demonstrate monitoring
GET/api/export/predictions.csvDownload prediction history as CSV
POST/api/retrain/feedbackTrain and compare a candidate using reviewed labels
POST/api/retrainFit and evaluate a new version, then promote it to active
